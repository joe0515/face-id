# Face ID 验收测试清单

> 本清单覆盖**必须真机目视确认**的部分。单元测试（52 用例 / 8 套件）只覆盖纯逻辑与时序，  
> 凡是牵涉窗口服务器、TCC 权限、摄像头、跨进程行为的一律无法自动化。
>
> 建议按顺序执行：前面的条目失败会掩盖后面的现象。

## 怎么用这份清单

- 每条前置一个复选框 `- [ ]`，**通过后就地勾选**（VS Code / Typora / Obsidian / GitHub 里可直接点击；打印出来则可手写打勾）。
- 每条下方那个方框就是**反馈框** —— 正常留空，只有失败或不符预期时才填。
- 反馈框里建议写三样：**实际现象**（跟期望差在哪）、**复现步骤**（做了哪几步）、**上下文**（哪个 App、几块屏、什么权限状态）。
- 每组末尾有一个「本组备注」反馈框，用于记录跨条目的观察。
- 文末有**结论汇总表**与**其他缺陷记录表**，用于归档。
- 结果只有两种：**符合期望** / **有问题**。不要写「基本正常」—— 不确定就记进反馈框。

## 已知未验证 / 已知限制（记录用，不是缺陷）

- **`.windowShield` 是否真的生效**取决于 `hide()` 之后 AX 是否仍报告窗口 —— 见 2.1。
- **Mission Control / Space 切换的泄漏面**是方案固有边界 —— 见 3.2 / 3.3。
- **私有 SkyLight API**（锁屏上绘制浮层）与**辅助功能权限**意味着无法上架 App Store；  
  Developer ID 分发也需自行评估公证风险。
- **ad-hoc 签名**：系统能记住辅助功能授权，但每次重新编译后 cdhash 变化 → 授权失效，需重新勾选；  
  会话密钥保护等级也只能停在「应用内校验」。
- 每个 App 的**独立会话时长 / 计时模式**在数据模型与内核层已支持  
  （`LockedApp.customSessionTimeout` / `timerFromFocus`），但设置界面目前只暴露全局值。
